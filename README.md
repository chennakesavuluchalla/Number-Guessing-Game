# 🎯 Number Guessing Game

Python Number Guessing Game with Easy/Medium/Hard levels + Win Streak 🏆

## Features
- **3 Difficulty Levels**: Easy (1-10), Medium (1-50), Hard (1-100)
- **Win Streak Tracking**: Keep your winning streak alive!
- **Emoji Feedback**: 🏆 for wins, ❌ for wrong guesses  
- **Input Validation**: Handles invalid inputs gracefully
- **Play Again**: Loop until you want to quit

## How to Run
python "Guess The Number.py"
